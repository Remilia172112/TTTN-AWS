# Event Report: AWS First Cloud AI Journey Community Day 2026

More than just knowledge-sharing sessions, this event was a journey from a solid systems administration foundation to the latest breakthroughs in Generative AI. Looking at the presented topics, the strong shift in technological trends is clearly visible.

### General Event Information

- **Event Name:** AWS First Cloud AI Journey Community Day
- **Time:** 09:00 AM - 12:00 PM, Saturday, March 21, 2026
- **Location:** AWS HCM Office, 26th Floor, Bitexco Financial Tower, Ho Chi Minh City

### List of Speakers

The event gathered top experts from various major tech companies:
- **Hai Bui** - Engineering Manager, GoTymeX
- **Phuc Dang** - Cloud Architect, GoTymeX
- **Phap Nguyen** - Cloud Engineer, VPBank
- **Phat Pham** - Software Engineer, Katalon
- **Nghi Danh** - AI Engineer, Renova Cloud
- **Phong Nguyen** - Senior Software Engineer, Sympli
- **Thinh Nguyen** - DevOps Engineer, FCAJ

### Highlighted Content (Based on Agenda)

#### 1. Building Modern Platform Engineering & Career Pathways (09:00 - 09:45 AM)
- **Platform Engineering Overview:** Defined the role of Platform Engineering as the "backbone" in modern Cloud and DevOps ecosystems.
- **Career Pathways:** Shared insights on company culture, internship opportunities, and sustainable career development paths for young engineers through a direct interactive Q&A session with industry experts.

#### 2. GenAIOps Essential - DevOps for Generative AI Applications (09:45 - 10:15 AM)
- **Bringing AI into Production:** Grasping the DevOps foundation on AWS and learning resources.
- **GenAIOps in Action:** Showcased real AWS projects integrating **Bedrock AgentCore** to build AI, deploying it on **EKS**, and solving system observability challenges using **Langfuse**.

#### 3. Shipping Code in the Agentic Era (10:15 - 10:45 AM)
- **Productivity Playbook:** How we write and deploy code is changing. This session opened up a new "productivity playbook."
- **Tools & Practice:** Detailed the current problems, took a Deep Dive into AI tools, and provided a live Demo on how engineers can leverage AI to boost productivity and tackle complex problems.

#### 4. Production-Grade Multimodal GenAI on AWS (11:00 - 11:30 AM)
- **"Hardcore" Techniques:** Explored The New AI Application Stack.
- **Core Technologies:** Ranging from Multimodal Search with **Nova Embeddings**, applying **GraphRAG** for enterprise knowledge bases, to setting up Multi-Agent Workflows. The ultimate goal is building Safe & Observable GenAI.

#### 5. From Edge To Origin: CloudFront as Your Foundation (11:30 - 12:00 PM)
- **Network Infrastructure Optimization:** Utilizing Amazon CloudFront as the foundation for every workload.
- **Comprehensive Benefits:** Analyzed how CloudFront aids in Cost optimization, Security capabilities, Enhanced reliability, and Enhanced performance for the system.

### Key Takeaways (What I Learned)

#### Foundational Mindset & Career
- Understood the importance of Platform Engineering in creating a seamless development environment. It is not just about technical skills, but also serves as a compass for a sustainable career path.
- Grasped how large enterprises evaluate and set expectations for young engineers.

#### Technical Architecture & Operations (GenAIOps)
- Learned how to take a GenAI model from idea to a production environment using the AWS ecosystem (Bedrock, EKS) and recognized the critical importance of Observability via Langfuse.

#### Optimization & Modernization Skills
- Mastered the tools of the "Agentic Era" to automate and accelerate the software development process.
- Enhanced knowledge of modern system architectures like GraphRAG, Multi-Agent workflows, and how to use CloudFront for content delivery optimization.

### Application to Work & Projects

- **Coding Process Optimization:** Apply the "Productivity Playbook" by integrating AI Agents into daily programming workflows (such as VS Code/GitHub) to boost efficiency.
- **Safe AI Deployment:** Propose using Langfuse to monitor, evaluate costs, and check API quality if implementing GenAI in upcoming graduation projects.
- **Cloud Optimization:** Utilize Amazon CloudFront knowledge to set up CDNs, configure caching, and enhance security for web applications (Static Website/API) on AWS.

### Event Experience

The event was an inspiring morning at the AWS office. My most memorable experiences were:

- **Highly Practical Perspective:** Instead of discussing general AI models, the speakers dived straight into real-world operations (GenAIOps, Bedrock, Langfuse), helping me clearly visualize enterprise-scale challenges.
- **Mindset Expansion:** The sharing sessions on the "Agentic Era" completely changed my coding mindset. Engineers will not be replaced by AI; rather, engineers who know how to use AI will create breakthrough value.
- **Networking & Connection:** The opportunity for direct conversation (Networking) during the Break with experts from GoTymeX, VPBank, Katalon, etc., helped answer many of my questions regarding my upcoming professional development path.
