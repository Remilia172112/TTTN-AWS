###  [Blog 1 - Building Event-Driven Applications with Amazon EventBridge](3.1-Blog1/)
This blog introduces Event-Driven Architecture (EDA) and how to apply it to build distributed microservices applications on the AWS platform. The article explains in detail the benefits of decoupling services to increase scalability and resilience. You will also dive deep into the core components of Amazon EventBridge, how to differentiate it from Amazon SQS/SNS, and examine a practical example of event filtering to optimize Lambda function invocation costs.

###  [Blog 2 - AWS Security Best Practices: Applying the Principle of Least Privilege](3.2-Blog2/)
This blog delves into how to securely manage identity and access on AWS through the IAM service. The article analyzes the risks of granting overly permissive rights (such as using the `*` wildcard) during development and provides guidance on establishing 3 comprehensive levels of access control. Additionally, you will learn how to use IAM Access Analyzer to scope down permissions, how to write least privilege policies, and how to apply Attribute-Based Access Control (ABAC) using Tags.
