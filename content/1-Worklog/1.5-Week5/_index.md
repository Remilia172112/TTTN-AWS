### Week 5 Objectives:

* Master core security concepts on AWS, including the Shared Responsibility Model and Identity and Access Management (IAM).
* Understand the operations and configurations of advanced security services such as Amazon Cognito, AWS Organizations, AWS Identity Center, AWS KMS, and AWS Security Hub.
* Practice implementing fine-grained access controls using Resource Tags and Permission Boundaries.
* Apply AWS Lambda to build automated cost optimization solutions for the AWS environment.
* Practice encrypting data at rest using AWS KMS.

### Week 5 Achievements:

* Clearly understood the security responsibilities between the customer and AWS according to the Shared Responsibility Model.
* Successfully established complex IAM policies, using Resource Tags for fine-grained access control to EC2 resources.
* Grasped how to restrict the maximum permissions of an IAM role/user using Permission Boundaries.
* Automated cost-saving processes by programming AWS Lambda functions to manage resource states.
* Successfully implemented data at rest encryption with AWS KMS, ensuring information safety according to security standards.
* Acquired the ability to deploy AWS Security Hub to evaluate and continuously monitor the security posture of the entire AWS environment.
