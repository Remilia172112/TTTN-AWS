### Week 7 Objectives:

* Understand the concept and architecture of a Data Lake, distinguishing it from a Data Warehouse.
* Master high-performance NoSQL databases using Amazon DynamoDB.
* Explore and practice the Analytics ecosystem on AWS (AWS Glue, Amazon Athena).
* Integrate data flows to perform data analysis and visualization via Amazon QuickSight.

### Week 7 Achievements:

* Deeply understood Data Lake architecture on AWS and the role of S3 as a centralized storage for unstructured/semi-structured data.
* Proficiently operated Amazon DynamoDB, understanding how to design Keys to optimize query performance for NoSQL databases.
* Successfully established a basic Data Analytics Pipeline: Used AWS Glue to discover schemas and Amazon Athena to query data without needing to load it into a traditional database.
* Successfully visualized raw datasets into vivid, easy-to-understand Dashboards to support business decision-making using Amazon QuickSight.
