### Week 3 Achievements:

* Deeply understood and differentiated AWS storage services (EBS for block storage, EFS/FSx for file storage).
* Grasped the operational mechanics of Auto Scaling for automatic resource adjustment, and learned when to use Lightsail instead of traditional EC2.
* Understood the concept and application of AWS MGN for migrating servers to the Cloud.
* Successfully deployed complex Lab models combining network infrastructure (VPC) and virtual servers (EC2).
* Proficiently managed AMIs and Key Pairs.
* Mastered the use of third-party Client software (MobaXterm, PuTTY) to administer Linux EC2 servers, including the skill to handle and convert security key formats (PEM to PPK).
